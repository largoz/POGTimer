# POGTimer — Roadmap

## Готово (1.0.3)

- [x] Локальний і мережевий (host-authoritative) режим таймера.
- [x] Кастомний unnamed-message канал з magic-фільтром, стійкий до
      реконекту (`EnsureUnnamedHook`).
- [x] Фазові підписи HURRY! / WARNING з конфігурованим порогом.
- [x] Тогл broadcast (host-only) з коректним "clear" пакетом при вимкненні.

## Заплановано / ідеї

- [ ] Конфігурована позиція оверлею на екрані (зараз захардкоджено
      правий верхній кут у `OnGUI`).
- [ ] Локальний color-blind / high-contrast режим для тексту таймера.
- [ ] Розглянути перехід з `OnGUI` на UGUI Canvas (як у [POGSpawner](../POGSpawner/)) —
      узгодити стиль рендерингу оверлеїв між модами проєкту.

## Відомі проблеми

- Немає репортованих — мережева синхронізація перевірена на реконектах і
  зміні лобі.
